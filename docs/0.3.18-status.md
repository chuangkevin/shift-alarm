# 0.3.18 Wi-Fi 重連與 USB 寫入

- 修正保存網路候選切換競態：前一個候選逾時後先呼叫 `WiFi.disconnect(false, false)`，等待 300 ms，再嘗試下一個候選，避免非同步斷線取消下一次 `WiFi.begin()`。
- 新增不含密碼的序列診斷：候選 index／SSID、連線逾時與 Arduino Wi-Fi status。
- `wifi_failover_policy_test` 以 UBSan 通過，ESP-IDF 5.3.2 credential-free build 通過；映像大小 1,648,640 bytes。
- USB 裝置 MAC `fc:01:2c:c9:9c:a8`。寫入前 app0 sequence 1、state VALID；0.3.18 寫入非執行中的 app1 `0x410000`，讀回 SHA-256 與來源均為 `738c4214c000011030085305760750749e061a8b88cb80048c87c6403f68d144`。
- 只寫入第二個 OTA 選擇 sector `0xf000`，sequence 2；重開後 state 為 VALID。未寫 bootloader、partition table、NVS、`alarm_nvs` 或 app0。
- 一般 NVS 與 `alarm_nvs` 刷寫前後 SHA-256 相同；重開輸出 `SHIFT_ALARM_READY v0.3.18`、`BOOT_WIFI_MODE SAVED`，無 panic／boot loop／storage fault。
- 現場只嘗試候選 index 0 `Mark`，逾時 status 1（`WL_NO_SSID_AVAIL`）。這證明自動重試有執行，但目前環境沒有可用的已保存 SSID；尚未完成成功回連與多候選切換的 RF 驗收。
