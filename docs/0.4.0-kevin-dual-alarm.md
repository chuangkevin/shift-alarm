# 0.4.x Kevin 雙人固定上班鬧鐘

本分支 `feat/kevin-dual-alarm` 專供 MAC `fc:01:2c:ca:15:88` 的第二顆裝置。它與原本 `alarm.sisihome.org` 的輪班鬧鐘分開部署，不共用裝置權杖、後端資料庫或 OTA 發布目錄。

## 使用方式

- `Kevin` 與 `晴晴` 都固定週一到週五上班。
- 每人各有「週一、二、三、五」與「週四」兩組鬧鐘。
- 每組最多八個時間；每一個時間可獨立啟用、停用或移除。
- 所有時間固定使用臺北時間（UTC+8）。規則保存在 ESP32 的 `alarm_nvs`，沒有 Tailscale 或後端時仍會響鈴。
- 同一個 `/calendar` 頁面同時管理兩人，不需要逐月建立班表。

## 獨立部署

```text
手機 ──同一 Wi-Fi / HTTP 80──> ESP32（Kevin 第二顆）
                                  │
                                  └──原生 Tailscale──> GN100 100.127.82.47:8239
                                                               │
                                                               └──rpi-matrix 100.126.226.79:8239
```

- 遠端入口：`https://morning.sisihome.org`，根路徑轉到裝置 `/calendar`。
- GN100 的 `:8239` 只綁定 Tailnet，代理到 rpi-matrix 的獨立 `shift-alarm-morning` 容器。
- rpi-matrix 資料目錄：`/home/kevin/DockerCompose/shift-alarm-morning/data`。
- 私有 `provisioning.h` 使用 `http://100.127.82.47:8239`、`https://morning.sisihome.org` 與此裝置專用權杖。權杖與帶憑證韌體不得提交。
- 正常後續更新只發布至這個獨立後端，再由這顆裝置的 `/update` 做兩階段 OTA；不可把 0.4.x 發布到原本 `:8237` 的輪班裝置。
- 0.4.1 起，私有 `provisioning.h` 的權杖、後端與管理網址會在啟動時覆寫這顆裝置 NVS 中不相符的舊值，避免換機或分支切換後仍回連舊後端。
- 0.4.2 修正共用頁框誤刪頁面區域樣式之前全部內容的問題，並讓最近 30 秒內已有成功心跳時不因單次輪詢失敗誤報後端中斷。實機 USB 更新後已用瀏覽器確認兩張人員卡、四組時段、4 個鬧鐘列與後端可連線。
- 0.4.3 將裝置主畫面改為分別顯示 Kevin 與晴晴各自下一個已啟用鬧鐘的日期、星期與時間；倒數仍以兩人之中最先響的鬧鐘為準。已由 USB 寫入非執行中的 app0，保留原有 NVS、Wi-Fi、Tailscale 與雙人設定。

## 排程資料

保存的 schedule 新增 `weekly_profiles`：

```json
{
  "kevin": {
    "regular_times": ["07:00"],
    "thursday_times": ["07:00"],
    "disabled_regular_times": [],
    "disabled_thursday_times": []
  },
  "qingqing": {
    "regular_times": ["07:00"],
    "thursday_times": ["07:00"],
    "disabled_regular_times": [],
    "disabled_thursday_times": []
  }
}
```

韌體每次直接從每週規則計算下一次與到期鬧鐘，不把有限天數預先展開，所以不會在數週後停止。相同時間的兩人鬧鐘合併成一次響鈴並顯示兩人姓名。

## 驗證基準

- USB 裝置識別：ESP32-S3、16 MiB Flash、8 MiB PSRAM、MAC `fc:01:2c:ca:15:88`。
- 更新前先保存該裝置私有完整備份並核對兩份 OTA metadata；只寫非執行中的 app 分區與一個新的 OTA metadata sector。
- 必驗：兩人的一般日時間、兩人的週四時間、四組個別開關、重開保存、週末不響、裝置頁下一次鬧鐘、後端回連與 `morning.sisihome.org`。
