# 0.3.25 交貨前驗收狀態

0.3.25 與後端 0.1.8 已部署；實機頁面驗收發現 Wi-Fi 管理內嵌 JavaScript 有 SyntaxError，整段 Wi-Fi UI 沒有執行。修正候選改為 0.3.26。

## 本次修正

- 主畫面 Wi-Fi 圖示：已連線顯示 1–4 格 RSSI；連線中顯示提示；離線顯示叉號。只有狀態／格數變化才更新 30×22 區域。
- Wi-Fi 管理頁新增「重新掃描附近網路」，用 nonce-protected POST 啟動 async scan；不再只依賴 failover 快取。
- 手動新增 Wi-Fi 在 `WiFi.disconnect()` 後以 rollover-safe deadline 等滿 300 ms 才 `WiFi.begin()`。
- AI 模型在 HTTP timeout／transport error 時也會在整體 deadline 內切換下一條 route。
- OTA install 無論是否提供 backend 都比對方向、班表模式、關屏時間、亮度、連續班、revision 與鬧鐘數；有 backend 時另驗 Tailscale identity／routing。
