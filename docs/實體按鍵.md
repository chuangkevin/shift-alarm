# 實體按鍵

韌體 0.3.12 使用左、中、右三鍵操作 240×240 畫面。

## 主畫面與選單

- 主畫面短按左鍵或右鍵：開啟選單並移動選項。
- 選單短按左鍵或右鍵：移動選項。
- 選單短按中鍵：進入選取頁面。
- 詳細頁短按中鍵：返回選單。
- 詳細頁短按左鍵或右鍵：切換詳細頁。
- `連線狀態` 顯示目前 SSID 與 `已保存 N 組`，不顯示密碼；Wi-Fi 增刪仍只在手機頁操作。
- 選單或詳細頁 15 秒沒有按鍵操作：返回主畫面。
- 長按中鍵至少 1.2 秒：放開後關屏。按住期間不重複觸發。
- 關屏時按任一鍵：只喚醒，不同一次操作選單。

## 優先行為

- 鬧鐘開始後新按下任一鍵：立即停鈴，不切換頁面、不關屏。響鈴前已按住的鍵須先完全放開，再按一次才會停鈴。
- 左鍵與右鍵同按 10 秒：啟動配網。兩鍵放開後不補送個別短按。
- 響鈴優先於配網與選單。同一輪配網倒數完成且鬧鐘到期時只會響鈴；已開啟的配網熱點也會關閉。
- 原有貪睡時間與排程資料不因畫面操作變更。

目前只有來源碼、host 測試與 ESP-IDF 建置驗證。第二台裝置燒錄前，按鍵手感、實體方向、顯示可讀性與響鈴優先行為仍未完成硬體驗收。
